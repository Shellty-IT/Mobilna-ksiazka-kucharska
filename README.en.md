# Mobile Cookbook

[Wersja polska](README.md)

A modern PWA that helps users discover recipes from available ingredients, check how to prepare products, and use a kitchen timer.

## Features

- ingredient-based recipe search with match ranking;
- matching and missing ingredient information;
- product catalogue with cooking guidance;
- kitchen timer;
- responsive layout for phones, tablets, and desktops;
- installable PWA with cached application assets and recipe data.

## Requirements

- Node.js 20.19 or newer;
- npm 10 or newer;
- a Firebase project with Authentication and Realtime Database.

## Getting started

```bash
npm install
npm run dev
```

The application starts at `http://localhost:3010` by default.

## Firebase configuration

Copy `.env.example` to `.env` and set the `VITE_FIREBASE_*` variables. The public project configuration is available as a fallback, while environment variables make it possible to use a separate Firebase project.

## Commands

```bash
npm run dev      # development server
npm run build    # production build
npm run preview  # local production preview
npm test         # ingredient-search tests
```

## Project structure

```text
src/
├── components/  # layout and feedback UI
├── hooks/       # data hooks
├── lib/         # search and normalization
├── pages/       # application screens
├── services/    # Firebase access and cache
└── firebase/    # Firebase initialization
```

## PWA

The manifest and service worker are generated by `npm run build`. Once deployed, the application can be installed from the browser. The application shell is precached and recipe data uses a NetworkFirst strategy with a cached fallback.

## Deployment

Netlify configuration is available in `netlify.toml`. The production build is published from the `dist` directory.
